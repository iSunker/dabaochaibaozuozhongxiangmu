#### 26.5.2 ★★ `notice` 定案：**不搬，保持启用**（2026-09-17 晚）

**用户提问**：「dsm 的 loop 任务停了，但是 notice 还在，这个 notice 能不能也弄到 docker 里面去？

**① 先确认实体**（没猜）：`notice` 在仓库里 `grep` **0 命中** ⇒ 它是**面板上的显示名**。
用 `sudo /usr/syno/bin/synoschedtask --get` 读出真身：

| ID | Name | State | Command |
|---|---|---|---|
| 9 | `reseed-drive-loop` | **disabled** | `sh …/drive-loop/run.sh` |
| **10** | **`reseed-notify-drain`** | **enabled** | `sh …/notify/notify-spool.sh` |

⇒ **`notice` = ID 10 `reseed-notify-drain`。**

**② 可行性判据（`grep` 说话，不是推断）**：
